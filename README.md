# AI Math Tutor

AI-powered mathematics tutor for school students.

## About

AI Math Tutor is a small educational project designed to
help school students understand mathematics through
step-by-step explanations.

## Features

- Solves mathematics problems
- Provides step-by-step explanations
- Designed for school students
- Uses AI to generate explanations

## Technologies

- Python
- OpenAI API
